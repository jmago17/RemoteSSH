# CLAUDE.md — RemoteSSH

Guidance for working in this repo.

## Toolchain (important)

- This Mac runs **macOS 27**, so **Xcode 26 will not launch**. Always use the
  beta: prefix build commands with
  `export DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer`.
- iOS **26** minimum deployment target; built against the iOS 27 SDK.

## Project generation

- The `.xcodeproj` is generated by **XcodeGen** from `project.yml` and is
  git-ignored. After adding/removing source files or editing `project.yml`,
  run `xcodegen generate`.
- Bundle id: `com.danobat.RemoteSSH`. Personal sideload only — no App Store
  signing configured.

## Build / verify

```sh
export DEVELOPER_DIR=/Applications/Xcode-beta.app/Contents/Developer
xcodebuild -project RemoteSSH.xcodeproj -scheme RemoteSSH \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```

`xcodebuild` is the source of truth. The editor's live SourceKit diagnostics
show false "Cannot find type" errors for loose files because they aren't indexed
as a target — trust a clean `xcodebuild` over those.

## Conventions

- **Swift 6 strict concurrency.** Citadel's `SSHClient` is non-Sendable. Keep
  all SSH work inside nonisolated async functions in `TmuxService`; pass only
  `Sendable` values across the `@MainActor` boundary. Do not store a
  `RemoteShell`/`SSHClient` on an actor.
- Secrets go in the **Keychain** (`KeychainStore`), never UserDefaults or disk.
- SwiftUI: MV pattern — `@Observable` model injected into views; no view models
  per screen beyond `SessionListModel`.
